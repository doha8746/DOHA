# 도하커피 인스타그램 포스터

피드에 올리는 **브랜드 포스터**. 명함(`../명함/`)과 달리 한 장이 그 자체로 완결된 매체다.

## 파일

| 파일 | 크기 | 용도 |
|---|---|---|
| `01-피드-4x5.png` | 1080 × 1350 | **메인** — 세로를 가장 길게 써서 화면 점유율 최대 |
| `02-피드-1x1.png` | 1080 × 1080 | 정사각 · **프로필 그리드가 잘리지 않는 안전한 선택** |
| `03-스토리-9x16.png` | 1080 × 1920 | 스토리 · 릴스 커버 |
| `도하커피-포스터.html` | — | 원본 소스 (텍스트 수정 후 재출력) |

## 구성

```
  로고 락업 (심볼 + DOHA COFFEE)
  ────────────────────────────
  커피는
  오로지 [맛]          ← 흰 색면 + 검은 글자
  달고나 같은 …
  ────────────────────────────
  ▬ (브랜드컬러 괘선 64px)
  이도하 · 로스터 · 바리스타 · 커피 클래스 강사
  국가자격 평생교육사 · 8년 · 800명+ 교육 · 전남 나주 로스터리
  INSTAGRAM  @doha_coffee_bar
  YOUTUBE    커피는 오로지 맛 핸드드립 도하커피
```

**명함과 다른 점 — 전화·이메일·주소를 넣지 않는다.**
포스터는 피드에서 스쳐 지나가는 매체다. 즉시 행동으로 이어지는 채널(인스타·유튜브)만 남기고,
개인 연락처는 프로필 링크에 맡긴다. 정보를 줄일수록 슬로건이 살아난다.

## '맛'이 흰 블록인 이유

브랜드컬러 `#7D2D36`은 명도 33%로 어둡다. 검정 배경 위에 색면으로 깔면
**형태만 보이고 색은 읽히지 않는다.** 흰 색면은 검정에서 얻을 수 있는 최대 대비이고,
포스터 전체에서 **가장 밝은 한 점**이 되어 스크롤을 멈추게 한다.
브랜드컬러는 괘선과 라벨 같은 **가는 요소**에서 제 색이 살아난다.

## 업로드 시 주의

- **프로필 그리드는 정사각으로 잘린다.** 4:5로 올리면 그리드 썸네일에서 상단 로고와 하단 정보가 날아간다.
  그리드 모양을 신경 쓴다면 `02-피드-1x1.png`를 쓴다.
- 스토리 버전은 상단·하단 300px를 **인스타 UI 세이프존**으로 비워뒀다.
- 업로드는 **원본 PNG 그대로**. 카톡 등을 거쳐 재압축된 파일을 올리면 검정 바탕에 블록 노이즈가 생긴다.

## 서체

- **본문: 본명조(Noto Serif KR)** — 구글폰트에서 자동으로 불러온다.
- **로고 워드마크와 인스타 핸들만 산세리프(Pretendard).**
  로고는 고정 자산이라 서체를 바꾸지 않고, 라틴 핸들은 명조에서 언더스코어가 뭉친다.

명조는 가로획이 얇아 **검정 바탕 + 흰 글자**에서 획이 날아간다.
그래서 모든 글자를 **굵기 500 이상**으로 고정했다. 400으로 내리지 말 것.

## 수정 방법

`도하커피-포스터.html`의 텍스트를 고친 뒤 재출력한다.

```bash
CH=/opt/pw-browsers/chromium-1194/chrome-linux/chrome   # 또는 로컬 Chrome 경로
"$CH" --headless=new --hide-scrollbars --force-device-scale-factor=1 \
  --window-size=1080,1550 --screenshot=_raw.png \
  "file://$PWD/도하커피-포스터.html#feed45"
# _raw.png 상단 1080×1350만 잘라 쓴다 (해시: #feed45 / #square / #story)
```
