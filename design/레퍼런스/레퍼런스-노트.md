## 1. 두 레퍼런스가 공유하는 것 — 이게 핵심이다

### ① 사진이 바탕이다
단색 배경이 아니다. **실제 공간과 사람이 먼저 보이고**, 글자는 그 위에 얹힌다.
그래픽이 주인공인 포스터가 아니라, **사진이 주인공이고 글자가 거드는** 구조다.

### ② 글자에 손의 흔적이 있다
- ①: 창문에 직접 쓴 듯한 **노란 필기체** `COMMON SPACE`
- ②: 두꺼운 **분홍 브러시 레터링** `책 읽는 ACC`

둘 다 정갈한 타입세팅이 아니다. **획의 굵기가 일정하지 않고, 기울기가 살아 있다.**

### ③ 정보가 "패널"이 아니라 "주석"으로 흩어진다
정보 블록을 따로 만들지 않는다.
- ①: `Open daily 7.00-19.00`이 창틀 옆 빈 벽에, 주소는 종이 등(燈) 위에 — **사진의 빈 곳을 찾아 들어간다**
- ②: 손으로 그린 화살표가 레터링 사이를 잇고 `세(書)로 보다` `나누다` `잇다`가 작게 붙는다

### ④ 여백을 사진이 만든다
흰 여백이 아니라 **사진의 어두운 부분·빈 벽면**이 여백 역할을 한다.

## 2. 두 레퍼런스가 정반대인 것 — 하나를 골라야 한다

| | ① COMMON SPACE | ② 책 읽는 ACC |
|---|---|---|
| **온도** | 조용·따뜻 (갈색 `#352818` 계열, 나무·크림·자연광) | 시끄러움·발랄 (형광 분홍 + 시안) |
| **글자 크기** | 사진에 종속. 작고 겸손하다 | 사진을 덮는다. 크고 과장됐다 |
| **태도** | 다큐멘터리 — "여기 이런 공간이 있다" | 이벤트 홍보 — "이거 하러 오세요" |
| **정보량** | 최소 (영업시간·위치·계정) | 많음 (날짜·장소·QR·주최/협력기관 로고) |
| **브랜드 브리프 대응** | ③ 일상의 작은 행복 · ① 오로지 맛 | ① 재미 (발견의 즐거움) |

> **같은 "사진 + 손글씨"라도 이 둘은 다른 브랜드가 된다.**
> ①로 가면 조용한 장인, ②로 가면 친근한 놀이. 정해야 한다.

## 3. 현재 포스터와의 충돌 — 스타일 조정이 아니라 시스템 교체다

현재 확정안(`design/인스타-포스터/`)은 이렇다.

| | 현재 확정안 | 레퍼런스 방향 |
|---|---|---|
| 바탕 | **평면 검정** (사진 없음) | **사진** |
| 서체 | 본명조 (정갈한 활자) | **손글씨·브러시** |
| 컬러 | 블랙 · 화이트 · `#7D2D36` 3색 규율 | ① 따뜻한 갈색·크림 / ② 형광 분홍·시안 |
| 정보 | 하단 콜로폰에 정렬 | 사진 위에 흩뿌림 |

**충돌 지점 2개를 먼저 정리해야 한다.**

1. **①의 따뜻한 갈색·크림**은 *"커피 브라운·베이지 클리셰를 쓰지 않는다"*는 현재 규율과 **정면 충돌**한다.
   (`../명함/명함-디자인가이드.md` §9 하지 말 것)
2. **②의 형광 분홍·시안**은 `#7D2D36` 3색 체계와 **충돌**한다.

> 레퍼런스 방향으로 가려면 **컬러 규율을 다시 정하는 것**부터다.
> 현재 3색 체계를 유지한 채 사진만 깔면 어느 쪽도 아닌 어정쩡한 결과가 나온다.

## 4. 이 방향으로 가려면 반드시 필요한 것

### 사진 — 이게 없으면 시작이 안 된다
레퍼런스의 힘은 **전적으로 사진에서 나온다.** 스톡 이미지로는 재현되지 않는다.

필요한 컷 (나주 매장 기준):
- **공간** — 자연광 들어오는 시간대의 매장 전경 (①의 핵심 자산이 이것이다)
- **로스터기 / 원두** — 굽는 장면, 배출되는 원두
- **손** — 드립하는 손, 원두 고르는 손 (얼굴 없이 손만으로도 충분하다)
- **잔** — 완성된 한 잔, 자연광 아래

> 촬영 시점은 **자연광 시간대**로 고정. ①의 따뜻함은 조명이 아니라 **창으로 들어온 빛**이다.

### 손글씨 레터링
- 직접 쓴 글씨를 스캔해서 벡터화하는 쪽이 가장 강하다 (복제 불가능한 자산이 된다)
- 대안: 브러시 계열 한글 폰트
