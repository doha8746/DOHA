## 🧭 핵심 의사결정 요약

### 1. 브랜드 코어
- **한 줄 정의:** "감성이 아니라 '맛'으로, 감(感)이 아니라 '근거'로 증명하는 홈카페 커피"
- **브랜드 3축:** ① 오로지 맛(진정성) · ② 근거(신뢰) · ③ 일상의 작은 행복(따뜻함)
- **메인 슬로건:** "커피는 오로지 맛" (유지 확정)
- **최대 차별점(해자):** 국가자격 평생교육사 + 8년/800명+ 교육 실적 → "피셜 아닌 팩트" 콘텐츠 원칙
- **포지셔닝 빈자리:** "이론적으로 탄탄한데 집에서 따라 하기 쉬운" 사분면 = 도하커피 독점 영역

### 2. 콘텐츠 전략 — 6개 시리즈
| 시리즈 | 역할 |
|---|---|
| 「왜 맛없을까?」 | 유입·공감 |
| 「피셜 vs 팩트」 | 신뢰·차별화 (채널 정체성 최강) |
| 「쓴맛·신맛 상담소」 | 검색 유입 |
| 「실패 없는 추출」 | 실용·재현성 |
| 「한 잔의 행복」 | 저변 확대 |
| 「도하's Pick」 | 전환·수익화 |
- **전략 뼈대:** 유입(호기심) → 신뢰(팩트) → 전환(추천)
- **영상 문법:** 오프닝 3초 통증 자극 / 크리덴셜 자막 상시 / "왜" 코너 필수 / 클로징 CTA

### 3. GTM — 원두 & 클래스
- **대전제:** 유튜브 = 신뢰를 파는 엔진 (매출은 원두·클래스에서)
- **퍼널:** 시청자 → 카카오채널 친구(리드) → 첫 구매/체험 → 정기구독·정규 클래스·추천
- **원두:** 입문 → 취향(3종) → 하이엔드 → 정기구독 / 봉투 QR 추출가이드로 재유입
- **클래스:** 원데이 → 정규 4주 → 온라인 VOD(지역 한계 돌파) → 심화·B2B
- **CRM 허브:** 카카오톡 채널 (유튜브 구독자는 알고리즘 것, 카카오 친구는 우리 자산)
- **런칭:** 90일 (인프라 → 첫 전환 → 확장)
