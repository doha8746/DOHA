# 네이버 스마트스토어 → 한진 원클릭 택배 자동화

도하커피 주문 처리 자동화의 **기반(스캐폴드)**입니다.
네이버 스마트스토어 주문을 한진택배 **원클릭 택배** 업로드 양식으로 자동 변환해서,
구글 시트에서 바로 송장 출력이 가능하도록 만드는 것이 목표입니다.

```
[네이버 스마트스토어 주문]
        │  (엑셀 다운로드 또는 커머스API)
        ▼
[구글 시트: 네이버주문 탭]  ← 주문 원본을 "붙여넣기만" 하면 끝
        │  ⚡ 자동 변환 (버튼 없음, 붙여넣는 즉시 실행)
        ▼
[구글 시트: 한진송장 탭]    ← 한진 원클릭 업로드용으로 자동 정리됨
        │  ▶ 메뉴 "택배자동화 > 한진양식 CSV 다운로드" (출력할 때 한 번)
        ▼
[한진 원클릭 택배 > 대량접수 엑셀 업로드]
        ▼
[송장 출력]  🖨️
```

핵심: **네이버주문 탭에 붙여넣으면 한진송장 탭이 스스로 채워집니다.** 수기 입력·버튼 클릭 없음.

---

## 무엇이 들어있나

| 폴더 | 내용 | 언제 쓰나 |
|------|------|-----------|
| `apps-script/` | **구글 시트 안에서 도는 변환 엔진 (주력)** | "구글 시트에 바로" — 버튼 클릭으로 변환 |
| `python/` | 엑셀 파일 일괄 변환기 (보조) | PC/서버에서 파일로 대량 처리 |
| `docs/` | 설계·필드매핑·설치 가이드 | 셋업 및 컬럼 조정 |

## 빠른 시작 (Google Apps Script — 5분)

1. 구글 드라이브에서 새 **구글 시트** 생성 → 이름 예: `도하커피_택배자동화`
2. 상단 메뉴 **확장 프로그램 > Apps Script** 열기
3. `apps-script/Config.gs`, `apps-script/Code.gs` 내용을 각각 파일로 복사
   (`appsscript.json`은 프로젝트 설정 > 매니페스트 표시 후 교체)
4. 저장 → 시트로 돌아가 새로고침 → 상단에 **택배자동화** 메뉴가 생김
5. 메뉴 **택배자동화 > 초기 시트 세팅** 클릭 → `네이버주문` / `한진송장` / `_설정` 탭 자동 생성
   (첫 실행 시 권한 승인 팝업 → 본인 계정 허용)
6. 네이버 스마트스토어 발송관리에서 받은 주문 엑셀을 복사해 `네이버주문` 탭에 **붙여넣기**
   → ⚡ **그 즉시 `한진송장` 탭이 자동으로 채워집니다** (버튼 클릭 불필요)
7. 출력할 때만: 메뉴 **택배자동화 > 한진양식 CSV 다운로드** → 나온 파일을 한진 원클릭 택배 대량접수에 업로드

> 자동 변환을 잠깐 끄고 싶으면 `_설정` 탭의 체크박스를 끄면 됩니다.

자세한 단계는 [`docs/설정가이드.md`](docs/설정가이드.md) 참고.

## ⚠️ 반드시 먼저 할 일 — 컬럼 이름 맞추기

네이버 주문 엑셀 헤더와 한진 원클릭 업로드 양식 헤더는 **계정/시점에 따라 조금씩 다릅니다.**
이 스캐폴드는 흔히 쓰이는 컬럼명으로 기본값을 넣어두었지만, **실제로 다운로드한 파일의
헤더에 맞춰 딱 한 곳만 고치면 됩니다:**

- Apps Script: `Config.gs`의 `NAVER_COLS`, `HANJIN_COLS`, `MAPPING`
- Python: `python/config.yaml`

매핑 방법은 [`docs/필드매핑표.md`](docs/필드매핑표.md)에 정리했습니다.

## 확장 로드맵

- **지금(기반):** 엑셀 붙여넣기 → 버튼 변환 → CSV 업로드 (수동 트리거)
- **다음:** 네이버 커머스API로 신규 주문 자동 수집(트리거) → 무붙여넣기
- **그다음:** 한진 계약사면 EDI/연계 API로 송장번호 자동 회신까지

로드맵 상세는 [`docs/설계-아키텍처.md`](docs/설계-아키텍처.md).
