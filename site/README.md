# 도하커피 웹사이트 (원두 · 커피 클래스)

**커피는 오로지 맛** — 도하커피 브랜드를 위한 고급 원페이지 사이트.
정적 HTML/CSS/JS로만 만들어 어떤 기기·호스팅에서도 빠르게 로드됩니다.

## 디자인 컨셉 — "Roasted & Dalgona"

브랜드 문서(`../docs/`)에 뿌리내린 방향입니다. 흔한 커피 사이트 클리셰(크림색 + 세리프 + 테라코타)를 피하고, 도하커피의 진짜 자산에서 끌어냈습니다.

- **색** — 볶은 원두의 짙은 에스프레소 다크 베이스 + 녹아내린 **달고나 캐러멜 골드** 액센트(브랜드의 "달고나 같은 단맛"을 시각화)
- **타이포** — 고운바탕(맛·장인의 세리프) × IBM Plex Sans KR(신뢰) × IBM Plex Mono(근거·데이터). 세리프↔모노의 대비가 브랜드의 "맛 ↔ 근거" 긴장을 표현
- **시그니처** — 로스팅 단계에 따른 **"단맛 곡선"**. 로드 시 캐러멜 곡선이 그려지며 달고나 스윗스팟에서 빛남 ("맛 + 근거"를 한 장면에)

## 구성 (원페이지)

1. **히어로** — "커피는 오로지 맛" + 단맛 곡선 시그니처, 크리덴셜 칩
2. **단맛 (포지션)** — 산미↔단맛 스펙트럼, 로스팅·추출 원리
3. **근거 (EVIDENCE)** — 8년·800명+·국가자격·나주 매장 스탯 + 문제→원인→해결→재현
4. **원두 (BEANS)** — 입문 · 취향 3종 · 하이엔드 싱글오리진 · 구독(QR)
5. **클래스 (CLASS)** — 원데이 → 4주 정규 → VOD → 심화 (번호 매긴 사다리)
6. **방문 (VISIT)** — 나주 매장·카카오채널 CTA
7. **푸터**

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 마크업 · 콘텐츠 |
| `styles.css` | 디자인 시스템 · 토큰 · 반응형 · 애니메이션 |
| `main.js` | 스크롤 리빌, 곡선 드로잉, 카운트업, 모바일 메뉴 (의존성 0) |

## 보기 / 배포

브라우저에서 `index.html`을 열면 됩니다. 정적 파일이라 GitHub Pages, Netlify, Vercel, S3 등 어디에나 그대로 올릴 수 있습니다.

## 품질 기준 (검증 완료)

- 반응형: 375 / 768 / 1024 / 1440px
- 접근성: 키보드 포커스 링, 스킵 링크, `aria-label`, 대비 4.5:1+
- `prefers-reduced-motion` 존중 — 모션 끄면 전체가 즉시 표시
- **JS 없이도 전체 콘텐츠 표시** (리빌 상태는 `.js` 클래스로만 적용)
- transform/opacity 기반 애니메이션 · IntersectionObserver로 성능 확보

> 가격·주소·연락처·소셜 링크는 디자인 시안용 예시입니다. 실제 값으로 교체해 주세요.
> 폰트는 Google Fonts CDN을 사용합니다(운영 환경에서 정상 로드).
