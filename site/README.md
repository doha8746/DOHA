# 도하커피 웹사이트 (원두 · 커피 클래스)

**커피는 오로지 맛** — 도하커피 브랜드를 위한 원페이지 사이트.
정적 HTML/CSS/JS로만 만들어 어떤 기기·호스팅에서도 빠르게 로드됩니다.

## 디자인 — "Warm Ivory" (밝은 톤)

한국 커피 커머스 감성의 **밝은 웜아이보리** 톤. 흔한 커피 사이트 클리셰를 피하면서도, 도하커피의 자산에서 방향을 끌어냈습니다.

- **색** — 웜아이보리 페이퍼 + 소프트 샌드 타일 + **달고나 캐러멜** 액센트(브랜드의 "달고나 같은 단맛"을 시각화)
- **타이포** — 고운바탕(맛·장인의 세리프) × IBM Plex Sans KR(신뢰) × IBM Plex Mono(근거·데이터)
- **시그니처** — 로스팅 단계별 **"단맛 곡선"** (로드 시 캐러멜 곡선이 그려지며 달고나 스윗스팟에서 빛남)

## 구성 (원페이지)

1. **히어로** — "커피는 오로지 맛" + 단맛 곡선 시그니처
2. **단맛 (포지션)** — 산미↔단맛 스펙트럼, 로스팅·추출 원리
3. **근거 (EVIDENCE)** — 8년·800명+·국가자격·나주 매장 스탯 + 문제→원인→해결→재현
4. **이달의 라인업 01–04** — 원두 더미 + 넘버링 테이스팅 플라이트 *(블루보틀 레퍼런스 재구성)*
5. **싱글 오리진 (ORIGINS)** — 국기 메달리온 + 산지 스펙(생산지·재배고도·품종·등급·가공·Cupping) + QR 3종(스토어·카카오·추출가이드) + Roasted by Doha Coffee *(원두 라벨 재구성)*
6. **원두 (SHOP)** — 향미 필터 탭(산미·밸런스·다크·마일드) + 상품 그리드 + 담기/재입고 버튼 *(컬리형 커머스 재구성)*
7. **제철 (SEASON)** — 산지별 제철 캘린더(간트 차트) *("커피도 제철이 있어요" 재구성)*
8. **클래스 (CLASS)** — 원데이 → 4주 정규 → VOD → 심화 (번호 사다리)
9. **방문 (VISIT)** — 나주 매장·카카오채널 CTA / **푸터**

> 4·5·6·7번 섹션은 사용자가 제공한 레퍼런스/라벨 이미지들의 레이아웃을 도하커피용으로 재구성한 것입니다. 원두 봉투·국기·산지 바 등은 저작권 있는 사진 대신 **순수 CSS/SVG로 그린 목업**입니다. 국기는 정확한 국기를 원형 메달리온으로 표현했습니다(정확한 국가 지도 실루엣 대체).

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 마크업 · 콘텐츠 |
| `styles.css` | 디자인 시스템 · 토큰 · 반응형 · 애니메이션 |
| `main.js` | 스크롤 리빌, 곡선 드로잉, 카운트업, 향미 필터, 캘린더 바, 모바일 메뉴 (의존성 0) |

## 보기 / 배포

브라우저에서 `index.html`을 열면 됩니다. 정적 파일이라 GitHub Pages, Netlify, Vercel, S3 등 어디에나 그대로 올릴 수 있습니다.

## 품질 기준 (검증 완료)

- 반응형: 375 / 768 / 1024 / 1440px
- 접근성: 키보드 포커스 링, 스킵 링크, `aria-label`/`aria-pressed`, 대비 4.5:1+
- `prefers-reduced-motion` 존중 — 모션 끄면 전체가 즉시 표시
- **JS 없이도 전체 콘텐츠 표시** (리빌 상태는 `.js` 클래스로만 적용)
- transform/opacity 기반 애니메이션 · IntersectionObserver로 성능 확보

> 상품명·가격·주소·연락처·소셜 링크는 디자인 시안용 예시입니다. 실제 값으로 교체해 주세요.
> 폰트는 Google Fonts CDN을 사용합니다(운영 환경에서 정상 로드).
