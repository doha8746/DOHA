# 도하커피바 경영 대시보드 (MVP v1)

> 매출·매입·원가율·손익분기점을 한 화면에서 보는 웹 대시보드. 직원도 함께 보되, 원가·순익 등 민감 지표는 사장에게만 보입니다.

- **작성 기준일:** 2026-07-02
- **연계 문서:** [브랜드전략 통합본](../docs/도하커피-브랜드전략-통합본.md)

---

## 1. 실행 방법

별도 설치 없이 브라우저만 있으면 됩니다.

- **바로 열기:** `platform/index.html` 파일을 더블클릭 (PC·휴대폰 모두 가능)
- **직원과 공유(권장):** GitHub Pages로 배포하면 링크만 보내면 됩니다.
  - 저장소 Settings → Pages → Branch를 이 브랜치로 지정 → 발행된 주소의 `/platform/` 으로 접속

데이터는 **접속한 기기(브라우저)에 저장**됩니다. 백업은 `설정 → JSON 내보내기`.

## 2. 화면 구성

| 탭 | 하는 일 | 사장 | 직원 |
|---|---|:---:|:---:|
| **대시보드** | 이달 매출·원가율·공헌이익·순익·손익분기 도달률·재고 | 전체 | 매출·재고만 |
| **일일 마감** | 매일 마감 시 매출(3사업부)·매입·원두 사용/입고 입력 | ✅ | ✅ |
| **메뉴 원가** | 레시피 입력 → 메뉴별 원가·원가율 자동 계산 | ✅ | ❌ |
| **고정비·손익분기** | 월 고정비 → 손익분기 월매출/일매출 자동 계산 | ✅ | ❌ |
| **설정** | 영업일수·재고 안전선·데이터 백업 | ✅ | ❌ |

우측 상단 **[사장 / 직원]** 토글로 뷰가 바뀝니다. (직원 뷰는 원가·순익·고정비 탭이 잠깁니다.)

> 첫 실행 시 이해를 돕기 위한 **샘플 데이터**가 채워져 있습니다. `설정 → 전체 초기화`로 비우고 실제 숫자를 넣으세요.

## 3. 계산 원리 (숫자가 어떻게 나오나)

- **메뉴 원가** = 원두(g)×원두단가 + 우유(ml)×우유단가 + 기타 부자재
  - 로스팅 원두 1g 단가 = 생두단가(원/kg) ÷ 1000 ÷ 로스팅수율
- **원가율** = 메뉴 원가 ÷ 판매가
- **변동비** = 마감에 입력한 매입액. 비우면 *평균 원가율 × 매출*로 자동 추정
- **공헌이익** = 매출 − 변동비 / **공헌이익률** = 1 − 변동비율
- **손익분기 월매출(BEP)** = 월 고정비 ÷ 공헌이익률
- **이달 순익(예상)** = 공헌이익 − 월 고정비

## 4. 사장님이 채워야 정확해지는 값 (Intake)

플랫폼은 이미 굴러갑니다. 아래를 실제 값으로 바꾸면 정확도가 올라갑니다.

### A. 메뉴 원가 탭
- [ ] 생두 단가(원/kg), 로스팅 수율(%), 우유 단가(원/L)
- [ ] 대표 메뉴 5~10개: 판매가 + 1잔당 원두(g)·우유(ml)·부자재(원)

### B. 고정비 탭
- [ ] 월세·관리비 / 인건비(사장 급여 포함 여부 결정) / 공과금 / 통신 / 카드·배달 수수료 / 감가상각 / 마케팅비

### C. 설정 탭
- [ ] 월 영업일수 / 원두 재고 안전선(g) / 현재 원두 재고(g)

### D. 매일 (일일 마감 탭)
- [ ] 매장음료·원두판매·클래스 매출 / (가능하면) 실제 매입액 / 원두 사용·입고량

> **POS·스마트스토어 CSV 자동 연동**은 2단계에서 붙입니다. 지금은 하루 매출 합계만 넣어도 지표가 나옵니다.

---

## 5. 다음 단계 (2단계 로드맵)

지금은 **1인용(기기 저장)** MVP입니다. 지표가 안정되면 아래로 승격합니다.

1. **공용 서버 + 로그인** — 사장·직원이 같은 데이터를 실시간 공유
2. **POS·스마트스토어 CSV 업로드** — 매출 자동 취합, 수기 입력 최소화
3. **월별 추이·전월 대비·목표 관리** — 시계열 그래프, 사업부별 손익계산서
4. **재고 자동 차감·발주 알림** — 레시피 기반 원두 소진 추적

*권장 순서: 먼저 이 화면으로 "우리 원가율·손익분기"를 손에 익힌 뒤 2단계로.*
