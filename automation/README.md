# 도하커피 주문 자동화 (네이버 스마트스토어 → 한진 원클릭 택배)

네이버 스마트스토어 주문을 구글 시트에 붙여넣기만 하면 **한진 원클릭 택배 업로드용 엑셀**이
자동으로 만들어지고, 거기서 **주문 이력·고객 관리·발송 후 팔로업 문자·로스팅 집계**까지
한 시트에서 굴러가는 시스템입니다.

```
[네이버 주문 엑셀 다운로드]
        │  열기(비번) → 전체 복사
        ▼
[구글시트 · 네이버주문 탭에 붙여넣기]   ← 여기까지가 사람이 하는 일
        │  ⚡ 자동 변환 (버튼 없음)
        ├──────────────┬───────────────┬────────────────┐
        ▼              ▼               ▼                ▼
   [한진송장]      [주문내역]       [고객관리]        [문자관리]
   엑셀 다운로드    주문 누적        단골 집계        안부·재구매
        │                                            [로스팅집계]
        ▼                                            원두별 수량
[한진 원클릭 대량접수 업로드 → 송장 출력 🖨️]
```

## 설치 (한 번만)

1. [sheets.new](https://sheets.new) 로 새 구글 시트 생성 → 이름 `도하커피_택배자동화`
2. **확장 프로그램 → Apps Script** 열기
3. [`apps-script/전체코드.gs`](apps-script/전체코드.gs) 내용을 통째로 복사 → 편집기에 붙여넣기 → 저장
4. 시트 새로고침 → 상단 **택배자동화** 메뉴 → **① 초기 시트 세팅** (권한 허용)

> `전체코드.gs` 한 파일에 모든 기능이 들어 있습니다. (`Code.gs`+`Config.gs`는 핵심 변환만 담은 분리형)

## 매일 쓰는 법

1. 네이버에서 주문 엑셀 다운로드 → 열기(비번) → 전체 복사
2. **`네이버주문` 탭 A1에 붙여넣기** → `한진송장` 자동 완성 ⚡
3. 메뉴 **택배자동화**에서 필요한 것 실행:
   - **한진양식 엑셀 다운로드** → 나온 `.xlsx`를 한진 원클릭 대량접수에 업로드 → 송장 출력
   - **로스팅 집계** → 오늘 볶을 원두 종류·수량
   - **주문내역에 누적하기** → 주문 이력 쌓기(주문번호 기준 합침)
   - **고객관리 갱신** → 단골·재구매 분석
   - **문자관리 갱신** → 발송 4일/10일 뒤 안부·재구매 문자 대상·문구

## 주요 기능

| 기능 | 설명 |
|------|------|
| 자동 변환 | `네이버주문` 붙여넣으면 `한진송장` 즉시 생성(onEdit) |
| 한진 실제 양식 | 받으시는 분·전화·핸드폰·우편번호·총주소·수량·품목명·운임Type·출고번호·특기사항 등 |
| 엑셀(.xlsx) 다운로드 | 한진송장 탭만 담은 엑셀 파일 생성(대량접수 업로드용) |
| 우편번호 5자리 보정 | `3968` → `03968` 앞자리 0 복구 |
| 전화번호 정규화 | `01012345678` → `010-1234-5678` |
| 송장/주문 병합 | 같은 주문의 여러 상품을 한 줄로(품목 합산, 수량 합산) |
| 주문내역·고객관리 | 주문 누적 + 고객별 총주문·수량·구매상품·기간 집계 |
| 문자관리 | 발송일 기준 안부(+4)/재구매(+10) 대상·완성문구 자동 정리 |
| 로스팅집계 | 오늘 주문의 원두별 수량 합계(총 봉수) |

## 컬럼이 안 맞을 때

이 도구는 **열 이름으로** 값을 찾으므로 열 순서는 상관없습니다. 실제 파일 헤더가 다르면
`전체코드.gs` 위쪽 `NAVER_COLS` / `HANJIN_COLS` / `MAPPING`만 고치면 됩니다.
자세한 내용은 [`docs/필드매핑표.md`](docs/필드매핑표.md).

## 앞으로 확장 (선택)

- 네이버 커머스API로 신규 주문 자동수집 → 붙여넣기 제거
- 한진 EDI/연계로 운송장번호 자동 회신
- 팔로업 문자 자동발송(알리고 등) 또는 매일 아침 대상 목록 메일 자동 발송
