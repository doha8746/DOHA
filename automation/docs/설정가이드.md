# 설정 가이드

두 방식 중 하나만 해도 되고, 둘 다 두어도 됩니다.
**"구글 시트에 바로"가 목표면 A(Apps Script)를 먼저 하세요.**

---

## A. Google Apps Script (주력, 권장)

### 1. 시트 만들기
1. [sheets.new](https://sheets.new) 로 새 구글 시트 생성 → 이름 예: `도하커피_택배자동화`

### 2. 스크립트 붙이기
1. 상단 메뉴 **확장 프로그램 → Apps Script**
2. 기본 `Code.gs` 내용을 지우고, 이 저장소 `apps-script/Code.gs` 내용 붙여넣기
3. 좌측 **＋ → 스크립트**로 파일 추가 → 이름 `Config` → `apps-script/Config.gs` 내용 붙여넣기
4. (선택) **프로젝트 설정 ⚙ → "appsscript.json 매니페스트 파일 표시" 체크** →
   `appsscript.json` 내용을 이 저장소 것으로 교체
5. 💾 저장

### 3. 컬럼 맞추기 (처음 1회)
- `Config.gs`의 `NAVER_COLS`, `HANJIN_COLS`, `MAPPING`을 실제 파일 헤더에 맞춤
- 방법은 [`필드매핑표.md`](필드매핑표.md)

### 4. 실행
1. 시트로 돌아가 새로고침 → 상단에 **택배자동화** 메뉴 생김
   (처음 실행 시 구글 권한 승인 팝업 → 본인 계정 허용)
2. **택배자동화 → ① 초기 시트 세팅** → `네이버주문`, `한진송장` 탭 생성
3. 네이버 주문 엑셀을 열어 데이터 복사 → `네이버주문` 탭 A1부터 붙여넣기
   (헤더 포함해 붙여넣어도 되고, 세팅이 만든 헤더 아래 데이터만 붙여도 됨)
4. **택배자동화 → ② 네이버→한진 변환**
5. **택배자동화 → ③ 한진양식 CSV 다운로드** → 링크로 파일 받기
6. 한진 원클릭 택배 **대량접수**에 그 CSV 업로드 → 송장 출력

### 5. (다음 단계) 주문 자동수집
네이버 커머스API를 붙이면 붙여넣기 단계를 없앨 수 있습니다.
- 키는 코드에 넣지 말고 **프로젝트 설정 → 스크립트 속성**에 저장,
  코드에서 `PropertiesService.getScriptProperties().getProperty('CLIENT_ID')`로 사용
- **트리거(시계 아이콘) → 시간 기반**으로 10~15분마다 신규 주문 수집 함수 실행
- 자세한 규격은 [설계-아키텍처.md](설계-아키텍처.md) 2단계 참고

## B. Python 변환기 (보조, 파일 일괄)

### 1. 설치
```bash
cd automation/python
pip install -r requirements.txt
```

### 2. 컬럼 맞추기
`config.yaml`을 실제 헤더에 맞게 수정 ([필드매핑표.md](필드매핑표.md)).

### 3. 변환
```bash
# 기본: 같은 폴더에 한진송장_날짜.csv 생성 (UTF-8 BOM)
python naver_to_hanjin.py 주문.xlsx

# 출력 파일 지정
python naver_to_hanjin.py 주문.xlsx -o 한진송장.csv

# XLSX로 출력
python naver_to_hanjin.py 주문.csv --xlsx

# 샘플로 동작 확인
python naver_to_hanjin.py sample/네이버주문_샘플.csv -o /tmp/out.csv
```

### 4. (선택) 자동화
- macOS/Linux `cron`, Windows 작업 스케줄러로 주기 실행
- 다운로드 폴더를 감시해 새 주문 파일이 오면 자동 변환하도록 확장 가능
