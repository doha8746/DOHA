# 도하커피 로고

## doha-mark.svg — 심볼(드리퍼 마크)

제공받은 로고 이미지(래스터, 355×204px)를 **벡터로 재현**한 파일.
원형 6개가 위에서 아래로 좁아지며 쌓이는 드리퍼 실루엣이다.

- `viewBox="0 0 47 37"` — 원본 마크 비율 그대로 (가로 47 : 세로 37)
- `fill="currentColor"` — **부모 요소의 글자색을 따라간다.**
  검정 배경에서는 흰색, 흰 배경에서는 검정으로 별도 파일 없이 전환된다.

```html
<span style="color:#fff"><svg …>…</svg></span>   <!-- 흰색 마크 -->
<span style="color:#7D2D36"><svg …>…</svg></span> <!-- 브랜드컬러 마크 -->
```

### 원본 대비 정확도
37개 행의 폭을 원본과 1:1 비교했을 때 총 오차 165px(행당 평균 4.5px / 마크 폭 47px 기준).
대부분 JPEG 압축·안티에일리어싱 노이즈 범위다.

> **인쇄 최종본에는 원본 벡터 파일(AI·EPS·SVG·PDF)을 쓰는 것이 원칙이다.**
> 이 파일은 원본을 받기 전까지 쓰는 **대체본**이다. 원본이 있으면 이 파일을 교체할 것.

## 워드마크 "DOHA COFFEE"

원본 로고의 워드마크는 **산세리프**다. 명함 본문이 명조체로 바뀌어도
**워드마크는 원본 그대로 산세리프를 유지한다** — 로고는 고정 자산이므로 서체를 바꾸지 않는다.

현재는 시스템 산세리프에 자간 `0.26em`을 주어 원본 비율(가로:캡높이 ≈ 9.8:1)에 맞췄다.
정확한 서체는 원본 벡터 파일에서 확인할 것.

## 최소 크기 / 여백

- **최소 크기:** 심볼 가로 6mm (그 이하는 아래쪽 좁은 띠가 인쇄에서 뭉갠다)
- **보호 여백:** 심볼 높이의 50%를 사방에 비운다
