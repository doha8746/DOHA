# 도하커피 명함 — 인스타그램용

인쇄용 90×50mm 명함(`../도하커피-명함.html`)을 **인스타그램 업로드 규격**으로 재구성한 버전.
명함 앞면(후킹)과 뒷면(정보)을 **한 장 안에 위·아래로 합쳤다.**

## 파일

| 파일 | 크기 | 용도 |
|---|---|---|
| `01-피드-4x5.png` | 1080 × 1350 | **피드 기본** — 세로를 가장 길게 써서 화면 점유율 최대 |
| `02-피드-1x1.png` | 1080 × 1080 | 정사각 피드 · **프로필 그리드가 잘리지 않는 안전한 선택** |
| `03-스토리-9x16.png` | 1080 × 1920 | 스토리 · 릴스 커버 |
| `도하커피-명함-인스타.html` | — | 원본 소스 (텍스트 수정 후 재출력) |

## 인쇄용과 무엇이 다른가

| | 인쇄 | 인스타 |
|---|---|---|
| 규격 | 90×50mm 가로 | 1080px 세로 |
| 구성 | 앞면 / 뒷면 2장 | **한 장에 통합** (상단 검정=후킹, 하단 흰색=정보) |
| 최소 글자 | 1.9mm (약 7pt) | **22px 이상** |
| 로고 | 심볼 가로 5.6mm | 심볼 가로 **92~124px** |

> **인스타 피드는 휴대폰에서 가로 약 400px로 보인다.** 1080px 기준 22px 미만 글자는
> 실제로는 8px 이하로 축소돼 읽히지 않는다. 그래서 인쇄본보다 **모든 글자를 키우고 정보를 덜어냈다.**

## 업로드 시 주의

- **프로필 그리드는 정사각으로 잘린다.** 4:5로 올리면 그리드 썸네일에서 상단 로고와 하단 정보가 날아간다.
  그리드 모양을 신경 쓴다면 `02-피드-1x1.png`를 쓴다.
- 스토리 버전은 상단 300px · 하단 280px를 **인스타 UI 세이프존**으로 비워뒀다.
  (프로필 바·답장 입력창에 가려지는 영역)
- 업로드는 **원본 PNG 그대로**. 카톡 등을 거쳐 재압축된 파일을 올리면 검정 바탕에 블록 노이즈가 생긴다.

## 수정 방법

`도하커피-명함-인스타.html`의 텍스트를 고친 뒤 재출력한다.

```bash
CH=/opt/pw-browsers/chromium-1194/chrome-linux/chrome   # 또는 로컬 Chrome 경로
"$CH" --headless=new --hide-scrollbars --force-device-scale-factor=1 \
  --window-size=1080,1550 --screenshot=_raw.png \
  "file://$PWD/도하커피-명함-인스타.html#feed45"
# _raw.png 상단 1080×1350만 잘라 쓴다 (해시: #feed45 / #square / #story)
```

## 서체

- **본문: 본명조(Noto Serif KR)** — 구글폰트에서 자동으로 불러온다.
- **로고 워드마크만 산세리프(Pretendard)** — 로고는 고정 자산이라 서체를 바꾸지 않는다.

명조는 가로획이 얇아 **검정 바탕 + 흰 글자**에서 획이 날아간다.
그래서 상단 후킹 존의 모든 글자는 **굵기 500 이상**으로 고정했다. 400으로 내리지 말 것.

폰트가 설치·로드되지 않으면 글자 폭이 달라져 줄바꿈이 깨진다. 재출력 시 반드시 확인할 것.
