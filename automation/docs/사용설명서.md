# 도하커피 택배 자동화 · 사용설명서 ☕

네이버 스마트스토어 주문을 구글 시트에 붙여넣기만 하면
**한진 송장 · 로스팅 · 주문이력 · 고객관리 · 팔로업 문자**가 한 번에 정리되는 시스템입니다.

---

## 1. 매일 하는 일 (딱 3분)

1. **네이버에서 주문 엑셀 다운로드**
   - 스마트스토어센터 → 발송(발주)관리 → 엑셀 다운로드
   - 파일 열기(비밀번호 입력)

2. **구글 시트에 붙여넣기**
   - 주문 엑셀에서 전체 선택(Ctrl+A) → 복사(Ctrl+C)
   - 시트 `네이버주문` 탭 **A1** 클릭 → 붙여넣기(Ctrl+V)
   - ⚡ 붙여넣는 순간 `한진송장` 탭이 자동으로 채워집니다 (버튼 없음)

3. **필요한 메뉴 실행** (상단 `택배자동화` 메뉴)
   | 하고 싶은 것 | 누를 메뉴 |
   |---|---|
   | 송장 뽑기 | **한진양식 엑셀 다운로드** → 나온 .xlsx를 한진 원클릭 대량접수에 업로드 |
   | 오늘 볶을 원두 확인 | **로스팅 집계 (오늘 볶을 원두)** |
   | 주문 이력 쌓기 | **주문내역에 누적하기** |
   | 단골·재구매 분석 | **고객관리 갱신** |
   | 안부·재구매 문자 대상 | **문자관리 갱신 (오늘 보낼 문자)** |

---

## 2. 탭별 설명

- **네이버주문** : 주문 원본을 붙여넣는 곳 (여기만 사람이 입력)
- **한진송장** : 한진 업로드용으로 자동 정리 (여기서 엑셀 다운로드)
- **주문내역** : 주문을 누적 기록 (같은 주문의 여러 상품은 한 줄로 합침)
- **고객관리** : 고객별 총주문·총수량·구매상품·첫/최근 주문일 (단골 순)
- **문자관리** : 발송 4일 뒤 안부 / 10일 뒤 재구매 문자 대상·문구
- **로스팅집계** : 오늘 주문의 원두별 수량 합계
- **_설정** : 자동변환 ON/OFF 스위치 (건드리지 마세요)

---

## 3. 문자관리 쓰는 법

1. 네이버에서 **발송처리(운송장 입력)** 를 해야 `발송일`이 채워집니다.
2. 주문을 `네이버주문`에 붙여넣고 → **주문내역에 누적하기**
3. **문자관리 갱신** 클릭
4. `문자관리` 탭에서 **`📮 오늘 보내기`** 로 표시된 사람의
   `안부문구` / `재구매문구`를 복사해서 문자로 발송

> 문구·날짜(4일/10일)는 `전체코드.gs` 위쪽에서 바꿀 수 있어요.
> `MSG_HELLO`, `MSG_REPURCHASE`, `FOLLOWUP_HELLO_DAYS`, `FOLLOWUP_REPURCHASE_DAYS`

---

## 4. 자주 묻는 문제

**Q. 붙여넣었는데 `한진송장`이 안 채워져요**
- `_설정` 탭 B1 체크박스가 켜져 있는지 확인
- 메뉴 → **지금 즉시 다시 변환** 눌러보기

**Q. 우편번호가 날짜로 나와요 / 앞자리 0이 사라져요**
- 코드가 자동으로 5자리·텍스트로 보정합니다. 그래도 이상하면
  `네이버주문` 탭을 비우고 **제목줄 포함** 다시 붙여넣기

**Q. 칸이 한 칸씩 밀려요**
- 주문 엑셀의 **제목줄(1행)까지 통째로** 복사해 붙여야 합니다
  (데이터만 붙이면 기존 제목과 어긋남)

**Q. 운임Type `신용`이 우리 계약과 달라요**
- `전체코드.gs`의 `'운임Type': { const: '신용' }` 값을 바꾸세요

---

## 5. 실제 파일 헤더가 바뀌었을 때

이 도구는 **열 이름으로** 찾으므로 열 순서는 상관없습니다.
네이버/한진 파일의 열 이름 자체가 달라졌을 때만 `전체코드.gs` 위쪽
`NAVER_COLS` / `HANJIN_COLS` / `MAPPING`을 실제 이름에 맞추면 됩니다.

---

## 6. 나중에 더 자동화하려면 (선택)

- **붙여넣기도 없애기** : 네이버 커머스API로 신규 주문 자동수집
- **문자 자동발송** : 알리고(aligo) 등 문자 API 연동, 또는 매일 아침 대상 메일 자동 발송
- **한진 송장까지 무인** : 한진 EDI/연계 계약

필요할 때 요청하면 이어서 붙일 수 있는 구조로 만들어져 있습니다.
